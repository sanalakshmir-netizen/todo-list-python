# To-Do List

A simple desktop To-Do List application built with Python and Tkinter.

## Features

- Add new tasks
- View tasks in a list
- Delete selected tasks
- Clear all tasks
- Warning messages for invalid actions
- Simple graphical user interface

## Technologies Used

- Python 3
- Tkinter
- Functions
- Lists
- GUI event handling

## How to Run

1. Make sure Python 3 is installed.
2. Open the project folder in PowerShell or Command Prompt.
3. Run:

```bash
python todo_list.py
